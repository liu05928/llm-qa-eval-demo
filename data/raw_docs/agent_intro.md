# Agent 入门介绍

Agent 通常指具有一定自主决策能力的智能体。和普通聊天机器人相比，Agent 不只是根据用户输入生成一句回答，而是可以根据任务目标进行观察、思考、行动，并根据行动结果继续调整下一步。

一个常见的 Agent 基本循环是：

1. Observe：观察当前环境或接收用户输入；
2. Think：分析当前任务，判断下一步应该做什么；
3. Act：调用工具、执行操作或生成输出；
4. Observe：再次观察执行结果；
5. Continue：根据结果继续推理或结束任务。

普通 chatbot 更像是“问一句答一句”。用户问什么，它就直接回答什么。workflow 更像是固定流程，例如按照预设步骤完成表单填写、信息提取或报告生成。Agent 则更强调根据任务动态选择工具和行动路径。

例如，用户说“帮我整理最近三天的重要邮件并生成待办事项”。普通聊天机器人无法直接完成，因为它不能主动访问工具。一个 Agent 系统则可以先调用邮件搜索工具，读取邮件内容，判断哪些邮件重要，再生成待办事项。

但是，并不是所有任务都适合使用 Agent。如果任务流程非常稳定、规则非常明确，用普通脚本或 workflow 反而更可靠。Agent 适合任务步骤不完全固定、需要根据中间结果动态决策、可能需要调用多个工具的场景。

在大模型应用开发中，Agent 常见于智能办公助手、自动资料分析、代码助手、数据分析助手和复杂任务规划等场景。学习 Agent 时，不能只关注概念，还要理解它和 chatbot、workflow、multi-agent 的区别。
