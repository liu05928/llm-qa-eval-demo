# RAG 入门介绍

RAG 的全称是 Retrieval-Augmented Generation，中文通常叫“检索增强生成”。它是一种将外部知识检索和大模型生成能力结合起来的方法。

普通大模型在回答问题时，主要依赖模型训练阶段学到的知识。如果用户提出的问题涉及最新资料、企业内部文档、课程资料或某个特定知识库，模型可能无法准确回答，甚至可能编造不存在的信息。这种现象通常被称为“幻觉”。

RAG 的核心思想是：在大模型回答问题之前，先根据用户问题从外部知识库中检索相关内容，再把检索到的内容作为参考资料提供给大模型，让模型基于这些资料生成答案。

一个基础的 RAG 系统通常包括以下步骤：

1. 文档读取：读取本地文档、网页、PDF 或数据库中的资料；
2. 文本切分：把长文档切分成多个较短的文本块；
3. 向量化：使用 embedding 模型把文本块转换成向量；
4. 向量存储：把文本向量保存到向量数据库中；
5. 相似度检索：用户提问后，将问题也转换成向量，并检索最相关的文本块；
6. Prompt 构造：把用户问题和检索到的文本块组合成提示词；
7. 答案生成：调用大模型生成最终回答；
8. 来源引用：返回答案时附带参考资料来源。

RAG 可以减少幻觉的原因在于，它让模型的回答有明确的资料依据。模型不再完全依赖自身记忆，而是优先参考检索到的知识片段。如果资料中没有相关信息，系统可以要求模型明确说明“资料中未提及”，而不是强行编造答案。

在教育场景中，RAG 可以用于课程资料问答、论文辅助阅读、学习笔记查询、教学资源检索和个性化学习辅导。例如，学生上传课程讲义后，可以向系统提问，系统先从课程资料中检索相关段落，再基于这些内容生成解释。
