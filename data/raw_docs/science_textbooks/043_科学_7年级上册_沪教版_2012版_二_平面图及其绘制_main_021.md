# 二、平面图及其绘制

校园能用实物模型表示，也能用图形表示。平面图就是常用的图形。校园模型能使我们对校园全貌一目了然。如果你从它正上方往下看，把它绘制成图形，就会得到校园平面图。平面图有哪些特点呢？你能读懂并绘制出来吗？

# 方向的辨别

我们已经对校园有了一些初步的认识，怎样才能进一步熟悉我们的校园呢？借助校园平面图是个好办法。
