# 二、土壤与植物

陆地上的植物生长在土壤中，似乎是天经地义的事。离开土壤，植物还能不能生长呢？

图10- 2- 1所示为无土栽培的植物。无土栽培可以不需要土壤，那么，土壤对于植物来说，究竟有何意义呢？

图10-2-1 无土栽培的植物

# 植物从土壤中获得了什么？

陆地上的植物，根总是扎到土壤中。若将植物从土壤中拔出后，它将会枯萎而死。我们已经知道，植物通过根从土壤中吸收水分。我们也知道，土壤的肥沃程度影响着农作物的生长。那么，根从土壤中还获得了什么？
