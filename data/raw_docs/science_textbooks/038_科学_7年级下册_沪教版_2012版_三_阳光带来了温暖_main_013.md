# 三、阳光带来了温暖

在寒冷的冬日，人们总是渴望温暖的阳光，许多动物也要利用阳光取暖（图1-3-1）。冷血动物由于不能保持恒定的体温，当气温变低时更需要晒太阳取暖。晒太阳的动物伸展躯体，并保持平展的身体与光线垂直，以获取尽量多的热量。你知道这种做法有什么道理吗？
